# URL Shortener

API para encurtar URLs, feita com FastAPI.

## Como rodar
1. `python -m venv venv` e `venv\Scripts\activate`
2. `pip install -r requirements.txt`
3. `uvicorn main:app --reload`
4. Abra http://localhost:8000/docs
